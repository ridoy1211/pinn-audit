Estimating heat diffusivity with physics-informed machine learning

Can a neural network recover how quickly heat spreads from a few noisy temperature readings, when the starting temperature is also unknown?

Ridoy Hasan · Physics graduate, Comilla University, Bangladesh
Completed computational studies; unpublished research.

One-page summary (PDF) Code and documentation Saved data and models

Main finding: neither method was consistently best in this heat-inversion study. Classical regularization changed the comparison, and a close fit to temperature readings did not guarantee reliable recovery of the underlying physical quantities. The main timing comparison remained inconclusive.

What I investigated

This is an inverse problem: infer the heat diffusivity and the unobserved starting temperature from later measurements. I compared a physics-informed neural network (PINN), trained using both measurements and the heat equation, with classical spectral inversion, which fits coefficients in heat-equation solutions.

The experiments examine four choices that can affect the comparison: classical regularization, the flexibility of the starting-temperature representation, the neural training budget, and when measurements are taken. The comparison uses the same observations and diffusivity bounds for both methods within each case.

What the results show

1. The baseline and recovery target matter

Classical regularization materially changed recovery. Some sparse-data comparisons favored the longer-budget PINN, while a richer-data comparison favored the classical method for recovering the full temperature field. The results support conditional advantages for the specified procedures.

The original study includes both favorable and unfavorable outcomes, with paired comparisons and uncertainty intervals. Read the original comparison.

2. The primary timing result is uncertain

For ten observations and starting field B, the prespecified comparison asks how switching from late to mixed observations changes the PINN error relative to the classical error. The median change was 3.73 percentage points, with a 95% bootstrap interval of −0.09 to 56.24. That interval leaves the direction unresolved.

The change is calculated within each independent block before summarizing. It is not the difference between marginal median errors. See the timing figure and analysis.

3. Fitting the readings is only part of the task

I examined whether the measurements distinguish diffusivity from an unknown starting profile, using fitted parameter profiles, matrix diagnostics and sensitivity checks. I also independently solved the heat equation using each timing PINN's recovered diffusivity and initial field, then compared that trajectory with the network's predictions.

The localized-profile test checks dependence on the original sine-based truths. Its forward solution was independently verified. It adds one robustness case, with a different initial energy and only two measurement schedules.

What this work establishes

The contribution is a controlled, reproducible comparison and an examination of why recovery can succeed or fail. It uses a one-dimensional synthetic heat problem, one true diffusivity and one absolute noise level. It does not establish performance on laboratory data, a new inverse algorithm, or universal superiority of either method.

Both fitting and diagnostic results are retained, including poor recovery and inconclusive comparisons. The protocols and analysis records distinguish development, frozen evaluation and later explanatory checks.

Methods, evidence and technical work

Tools used: Python, PyTorch, NumPy and SciPy; numerical heat-equation solutions; regularization and cross-validation; paired statistical comparisons; Git and reproducible analysis.
